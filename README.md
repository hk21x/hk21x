# hk21x

I build tools for problems I keep running into, and I reverse-engineer original Xbox games so they run natively on PC.

---

## 🎮 Original Xbox → native PC recompilation

These are static recompilation projects. Each one translates an original Xbox executable into native C++ so the game runs on modern PCs without an emulator.

## 🛠️ Self-hosted tools

- [**decide**](https://github.com/hk21x/decide): swipe-to-match film picker for your Plex library. Two to four people swipe, and it finds a film everyone wants to watch.
- [**downtimerr**](https://github.com/hk21x/downtimerr): schedules Plex maintenance windows through the Plex API, so your users get notice instead of a surprise.
- [**snapshotr**](https://github.com/hk21x/snapshotr): takes automated snapshots from RTSP cameras, so you can build timelines on cameras that can't do it themselves.
- [**catcherr**](https://github.com/hk21x/catcherr): monitors domain expiry and sends staged alerts by email and Discord webhook.
